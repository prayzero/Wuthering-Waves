# 3.7 추천 파티 재확인

확인일: 2026-11-09 (Asia/Seoul)

이번에는 여우의 별자리와 쇄명 공략을 재확인했습니다. 기존 98개 전체를 다시 검토하거나 성능 순위를 새로 계산한 작업은 아닙니다. 기존 3개 조합의 확인일·운용 조건을 갱신하고, 공략에 명시된 대안 6개를 추가하여 총 104개를 제공합니다.

자료는 모두 **커뮤니티 분석**입니다. 아래 3인 조합은 원문 시너지와 지원 슬롯 설명에 근거한 편집 결과이며 공식 추천이 아닙니다.

두 페이지의 표시 갱신일은 2026-10-22입니다. 이번 날짜는 원문 재확인일입니다. 합일의 복링 지원은 벨리나보다 낮은 우선순위인 대안으로 표시합니다. 기존 린네·모니에 편성에는 두 캐릭터 동시 사용과 쇄명의 메인 딜러 운용 조건을 보완했습니다.

여우의 별자리 페이지에는 금희만이 합일 파트너라는 과거 문장이 남아 있습니다. 같은 페이지의 쇄명 출시 후 설명과 쇄명 공략에 모순되므로 그 문장은 근거로 사용하지 않았습니다. 미출시 캐릭터나 확인되지 않은 조합은 추가하지 않았습니다.

자동 편성은 후보 안에서 파티 수와 입력한 육성·돌파·전무를 비교합니다. 실제 피해량·적 상성의 최적화나 지원 대안 간 동일 성능을 뜻하지 않습니다. 방랑자는 카드에 표시된 전도 속성으로 운용해야 합니다.
