# 鳴 WuWa 픽업 플래너

**명조: 워더링 웨이브** 픽업 계획 · 파티 편성 · 뽑기 기록 · 운 분석을 한 곳에서 관리하는 웹 도구입니다.
순수 HTML/CSS/JS 정적 사이트라 서버 없이 GitHub Pages에서 바로 동작하며, 모든 데이터는 브라우저 로컬 저장소(localStorage)에 저장됩니다.

## 기능

- **한눈에 보는 홈** — 현재 픽업, 보유 공명자, 편성 파티와 픽업 계획을 요약합니다.
- **빠른 탐색** — 데스크톱 사이드 메뉴와 모바일 하단 메뉴, 캐릭터 이름 검색을 제공합니다.
- **간결한 기록 화면** — 현재·예고 / 내 기록 / 전체 배너를 나누어 볼 수 있습니다.
- **캐릭터별 추천 파티** — 기본 캐릭터 57명을 포함하는 대표 조합 38개를 검색하고, 보유한 조합을 내 파티로 추가합니다.
- **육성 현황** — 보유 캐릭터별 Lv.90·스킬 레벨·에코·무기 레벨 완료를 체크하고 미완료 항목을 관리합니다.
- 재화 계산기는 홈 하단에서 펼치고, 육성 캐릭터를 고르면 계산 결과로 바로 이동합니다.

### 🏠 홈 · 플래너
- **픽업 일정** — 뽑을 캐릭터의 픽업 일정을 등록하면 **진행 중인 일정이 맨 앞**에 표시됩니다.
  D-day, 목표(명함~6돌/전무), 모아둔 뽑기 수 게이지(반천장 80 / 천장 160 마커)를 제공합니다.
- **파티 편성** — 보유 캐릭터를 **딜러 · 서브딜러 · 힐러**로 나눠 확인하고, 빈 슬롯 클릭 또는 **드래그 & 드롭**으로 파티를 짭니다.
  파티는 최대 3명이며, 일반 파티는 다른 모든 파티에서 사용 중인 캐릭터를 중복 편성할 수 없습니다. 탑·해역·매트릭스 등 콘텐츠를 선택한 파티만 다른 파티와 중복 편성할 수 있어요.

### 👥 보유 캐릭터
- 캐릭터 카드를 클릭하면 **흑백 ↔ 컬러**로 전환되며 보유 상태가 저장됩니다.
- 보유한 캐릭터만 파티 편성에 사용할 수 있습니다.
- 공식 목록에 아직 없는 미래 신규 캐릭터는 [신규 캐릭터 직접 추가]로 등록할 수 있어요.

### 추천 파티
- 홈의 **추천 파티** 또는 캐릭터 카드의 **추천 파티**에서 원하는 캐릭터를 선택합니다.
- 보유 인원이 많은 조합부터 표시하며, **모두 보유한 조합만** 필터를 지원합니다.
- 세 명을 모두 보유하면 일반/콘텐츠 파티로 새로 추가합니다. 기존 파티는 덮어쓰지 않으며 중복 편성 규칙을 유지합니다.
- 공략 기반 대표 조합이며 공식 추천이나 성능 순위가 아닙니다. 방랑자 속성 등 조건은 카드에, 근거는 펼친 출처에 표시합니다.
- [추천 38개와 출처·조건](docs/party-sources-2026-10-23.md)

### 육성 현황
- **보유 캐릭터 → 육성 현황** 또는 보유 카드의 **육성 0/4** 버튼에서 입력합니다.
- **Lv.90 완료 · 스킬 레벨 완료 · 에코 완료 · 무기 레벨 완료**를 각각 체크하거나 해제하면 즉시 저장됩니다. 스킬·에코·무기는 사용자가 목표로 정한 세팅의 완료 여부입니다.
- 보유한 기본·직접 추가 캐릭터를 검색하고, **미완료 / 모두 완료**로 모아 볼 수 있습니다.
- 기록은 현재 브라우저에 저장되며 JSON 내보내기·가져오기에 포함됩니다. 보유를 해제해도 보관되며 다시 등록하면 복원됩니다. 직접 추가 캐릭터를 삭제하면 해당 기록도 삭제됩니다.
- 이전 백업에 육성 기록이 없으면 모두 미체크로 표시합니다. 완료 여부로 재료 계산 결과를 자동 차감하지 않습니다.

### 🧭 스킬 재료 · 육성 계산
- 캐릭터별 **Lv.1→90 + 포르테 전 노드 만렙** 총 재료와 클램 코인을 확인할 수 있습니다.
- SOL3 단계 8 파밍 보상 기준으로 필요한 **결정 웨이브 플레이트와 자연 회복 일수**를 계산합니다.
- 단조·강적의 무작위 드롭, 주간 보스 제한, 재료 파밍 중 함께 받는 클램 코인과 방랑자 예외를 반영합니다.

### 📜 픽업 기록
- **역대 픽업 배너** 목록 (1.0 기염부터 3.7 여우의 별자리·쇄명까지, 복각 포함, 2026-10-23 공식 자료 확인).
- 진행 중인 배너는 한국 서버의 공식 시작·종료 시각을 반영합니다. 미공개 픽업 일정은 확정 정보와 분리합니다.
- **나의 뽑기 기록** — 배너별로 획득 결과를 기록:
  - 캐릭터: **명함 ~ 6돌** 선택 + 소모 뽑기 수 + 픽뚫 여부
  - 전무(무기): 이름 + **획득 개수(1~5재련)** + 소모 뽑기 수
- **시즌별 운 퍼센트** — 공식 확률 기반으로 "상위 몇 %의 운"인지 추산해서 시즌별로 보여줍니다.

### 🎲 확률 정보
- 공식 확률표: 5성 기본 0.8% / 종합 1.8%, **반천장 80뽑(픽뚫 가능) / 천장 160뽑(확정)**, 전무는 **80뽑 확정(픽뚫 없음)**, 픽업 획득 시 카운트 리셋.
- 뽑기 수에 따른 **누적 획득 확률 곡선** (호버 시 상세 수치).
- 운 퍼센트 계산 방식 설명. 소프트 천장(66뽑~) 상승 곡선은 공식 미공개라 커뮤니티 추정 모델을 사용합니다.

### 📱 앱으로 설치 (PWA)
- 브라우저 주소창의 설치 아이콘 또는 헤더의 **⬇ 앱 설치** 버튼으로 홈 화면에 설치할 수 있습니다.
- iOS Safari: 공유 버튼 → **홈 화면에 추가**.
- 설치 후에는 오프라인에서도 동작합니다 (서비스 워커 캐시).

## GitHub Pages로 보기

저장소 → **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하면
`.github/workflows/deploy-pages.yml` 워크플로가 푸시할 때마다 자동 배포합니다.

배포 후 주소: `https://<계정명>.github.io/Wuthering-Waves/`

> 또는 Source를 **Deploy from a branch**로 두고 배포할 브랜치 + `/ (root)`를 선택해도 됩니다 (정적 사이트라 빌드가 필요 없어요).

## 로컬에서 실행

검증: `node scripts/validate-site.mjs`, `node scripts/test-character-names.mjs`, `node scripts/test-app.mjs`, `node scripts/test-ui.mjs`, `node scripts/test-recommendations.mjs`, `node scripts/test-progress.mjs`, `node scripts/test-sw.mjs`.

```bash
# 아무 정적 서버로 열면 됩니다
python3 -m http.server 8000
# → http://localhost:8000
```

## 2026-10-23 정보 점검

- 3.7 후반: 쇄명 신규 / 루실라·린네 복각, 10월 22일 11:00 ~ 11월 11일 12:59 (한국). 4성은 루미·단근·치샤입니다.
- 여우의 별자리·쇄명의 속성, 무기, 전무, 공식 이미지, 스킬·돌파 소재를 추가했습니다. 공식 한국어 명칭을 확인하지 못한 신규 소재는 영문 원문을 사용합니다. 육성 수량 계산은 기존 공통 표준 모델입니다.
- 공식 이벤트 노트의 탑(10/12~11/9), 해역(9/28~10/26), 매트릭스(10/7~11/12) 일정을 반영했습니다. 정확한 리셋 시각은 공식 미확인입니다.
- 현재 버프·몹은 Encore와 별도 게임 화면·커뮤니티 자료를 대조하고 **교차 확인 자료 · 비공식**으로 구분했습니다. 탑 12개 층, 해역 공통 효과·금색 증표 3종·9~11단계 추가 저항·12단계 전후반 몹, 매트릭스 회로 4종·보스 순서를 제공합니다. 해역 7~11단계 전체 몹과 매트릭스 개별 공명자 강화 전체는 포함하지 않습니다.
- 일정의 반복 계산과 버프 자료의 적용 기간을 분리했습니다. 기간이 지난 자료는 접힌 영역에 표시하고, 출처마다 공식/비공식·확인 범위를 표시합니다.
