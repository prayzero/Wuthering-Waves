# 鳴 WuWa 픽업 플래너

**명조: 워더링 웨이브** 픽업 계획 · 파티 편성 · 뽑기 기록 · 운 분석을 한 곳에서 관리하는 웹 도구입니다.
순수 HTML/CSS/JS 정적 사이트라 서버 없이 GitHub Pages에서 바로 동작하며, 모든 데이터는 브라우저 로컬 저장소(localStorage)에 저장됩니다.

## 기능

### 🏠 홈 · 플래너
- **픽업 일정** — 뽑을 캐릭터의 픽업 일정을 등록하면 **진행 중인 일정이 맨 앞**에 표시됩니다.
  D-day, 목표(명함~6돌/전무), 모아둔 뽑기 수 게이지(반천장 80 / 천장 160 마커)를 제공합니다.
- **파티 편성** — 보유 캐릭터를 원하는 슬롯으로 **드래그 & 드롭**해서 파티를 짭니다.
  파티는 최대 3명, 여러 개의 파티를 만들 수 있고 빈 슬롯 클릭으로도 추가할 수 있어요.

### 👥 보유 캐릭터
- 캐릭터 카드를 클릭하면 **흑백 ↔ 컬러**로 전환되며 보유 상태가 저장됩니다.
- 보유한 캐릭터만 파티 편성에 사용할 수 있습니다.
- 3.0 이후 신규 캐릭터는 [신규 캐릭터 직접 추가]로 등록할 수 있어요.

### 📜 픽업 기록
- **역대 픽업 배너** 목록 (1.0 기염 ~ 2.7 갈브레나, 신규 캐릭터 기준).
- **나의 뽑기 기록** — 배너별로 획득 결과를 기록:
  - 캐릭터: **명함 ~ 6돌** 선택 + 소모 뽑기 수 + 픽뚫 여부
  - 전무(무기): 이름 + **획득 개수(1~5재련)** + 소모 뽑기 수
- **시즌별 운 퍼센트** — 공식 확률 기반으로 "상위 몇 %의 운"인지 추산해서 시즌별로 보여줍니다.

### 🎲 확률 정보
- 공식 확률표: 5성 기본 0.8% / 종합 1.8%, **반천장 80뽑(픽뚫 가능) / 천장 160뽑(확정)**, 전무는 **80뽑 확정(픽뚫 없음)**, 픽업 획득 시 카운트 리셋.
- 뽑기 수에 따른 **누적 획득 확률 곡선** (호버 시 상세 수치).
- 운 퍼센트 계산 방식 설명. 소프트 천장(66뽑~) 상승 곡선은 공식 미공개라 커뮤니티 추정 모델을 사용합니다.

## GitHub Pages로 보기

저장소 → **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하면
`.github/workflows/deploy-pages.yml` 워크플로가 푸시할 때마다 자동 배포합니다.

배포 후 주소: `https://<계정명>.github.io/Wuthering-Waves/`

> 또는 Source를 **Deploy from a branch**로 두고 배포할 브랜치 + `/ (root)`를 선택해도 됩니다 (정적 사이트라 빌드가 필요 없어요).

## 로컬에서 실행

```bash
# 아무 정적 서버로 열면 됩니다
python3 -m http.server 8000
# → http://localhost:8000
```
